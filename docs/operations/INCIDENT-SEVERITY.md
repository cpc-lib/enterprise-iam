- Confirmed cross-tenant leak
- Confirmed privilege escalation
- JWT signing key compromise
- Widespread unauthorized ALLOW

- Widespread authorization outage
- Widespread login outage
- Redis session outage
- Unsafe revocation behavior

## SEV-2
- Partial tenant degradation
- Audit delay
- Outbox backlog
- High latency

## SEV-3
- Minor/non-critical degradation
